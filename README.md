# Hoạt hình CS3

Repo Cloudstream gồm 5 extension: HH3D, YanHH3D, Anime47, AnimeHay và HHTQProvider.

Thêm URL sau vào Cloudstream → Settings → Extensions → Add repository:

`https://raw.githubusercontent.com/taigametaiwan/hoathinh-cs3/main/repo.json`

Các `.cs3` là bản biên dịch được cung cấp; repo này không chứa mã nguồn và chưa xác nhận khả năng phát của từng nguồn. Khi thay file `.cs3`, cập nhật `version`, `fileSize`, `fileHash` trong `plugins.json`.
